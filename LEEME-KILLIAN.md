# English Practice with Killian

Examen de práctica interactivo: prefijos OVER- y UNDER- (25 preguntas, 100 puntos).

## Cómo abrirlo (sin saber programar)
- **Computadora:** haz doble clic en `index.html`. Se abre en tu navegador (Chrome, Edge, Safari).
- **Celular o tableta:** envía el archivo `index.html` por WhatsApp o correo, descárgalo y ábrelo con Chrome o Safari. También puedes publicarlo gratis con GitHub Pages (Settings → Pages).
- Necesita internet solo para cargar las letras bonitas; sin internet funciona igual con otras letras.

El progreso se guarda en el navegador. El botón "Borrar progreso" empieza desde cero.
